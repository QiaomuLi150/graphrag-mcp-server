# Tool contracts (v1.0)

Generated by `tools/gen_contract_docs.py` from a live server: every example below is real output (request ids/latency are instance-specific). Contract version is returned in `meta.contract_version`; an incompatible change bumps the major version and ships under new tool names.

All tools are read-only (`readOnlyHint: true`), require scope `graph:read`, and are bounded: list sizes, hop counts, character budgets and response bytes are capped server-side. Errors are returned as MCP tool errors whose text is the JSON `ToolError` object `{code, message, retryable, request_id}`; transport/auth failures are HTTP 401/403.

Error codes: `INVALID_ARGUMENT`, `UNAUTHENTICATED`, `PERMISSION_DENIED`, `NOT_FOUND`, `RATE_LIMITED`, `TIMEOUT`, `DB_UNAVAILABLE`, `INSUFFICIENT_EVIDENCE` (reserved: absence of evidence is reported via `sufficient_evidence=false`, not an error), `INTERNAL_ERROR`.

      "maxLength": 128,

      "minimum": 1,
      "type": "integer"

      "default": 5,
