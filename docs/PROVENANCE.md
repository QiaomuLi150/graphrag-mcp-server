## Data
`data/demo/*` is generated deterministically (`SEED=20261123`) by `tools/generate_demo.py`. Names,
teams, services and "documents" are invented; there is no real company, customer, person or
credential data. Every source node carries the licence string `CC0-1.0 (synthetic ...)`.
No employer, customer or other third-party non-public material was used.

## Dependencies
Pinned in `uv.lock`. Notable: FastMCP 4.2.5 (Apache-2.0), neo4j driver 6.4.1 (Apache-2.0),
Pydantic, PyJWT, structlog. The local Compose file runs the Neo4j **Enterprise** image under the
Neo4j *evaluation* licence for local development only (needed for RBAC read-only roles and
multiple databases); see COST_AND_LIMITS for the managed-service implication.
